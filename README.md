# Naga Control

Программа для Razer Naga (MMOG): назначения боковой панели (слои 123 и NUM) и кнопок 4/5, профили программ, ступени DPI, подсветка, фильтр дребезга левой кнопки.

## Новое в 0.2

- **Макросы** — вкладка «Макросы»: запись с клавиатуры и мыши (реальные или фиксированные паузы), ручное добавление нажатий, пауз, сдвигов курсора и прокрутки колеса. Режимы: выполнить N раз, повторять пока кнопка зажата, повторять до повторного нажатия. Макрос назначается на кнопку действием «Макрос».
- **Запуск программ** — программа, ярлык, документ, папка или сайт с аргументами; кнопка «Обзор…», выбор окна (обычное, свёрнутое, развёрнутое, скрытое).
- **Команды как в Win+R** — строка выполняется так же, как из окна «Выполнить», но само окно не открывается: `%LOCALAPPDATA%`, `shell:startup`, `ms-settings:display`, `cmd /c …` (со скрытым окном консоль не мелькает).
- **Ввод текста** — символами (Unicode, не зависит от раскладки) или настоящими клавишами в выбранной раскладке (окно переключается на неё и обратно, Caps Lock учитывается); клавиша после текста, пауза между символами. Секрет/пароль хранится зашифрованным для учётной записи Windows (DPAPI) и в окне не показывается.
- **Подсказки на экране** перенесены в «Настройки»: положение со смещениями X/Y, ширина, высота, скругление, цвета, прозрачность, шрифт, длительность и затухание, предпросмотр без сохранения.
- **Фото мыши** во вкладке «Кнопки» (`web/mouse.png`): кнопки боковой панели и кнопки 4/5 выбираются кликом по фото, переназначенные отмечены точкой.
- **Окно настроек** запоминает размер, положение и развёрнутое состояние (`%APPDATA%\NagaControl\window.json`).
- **Частота проверки активного окна** задаётся в «Настройках» (250–30000 мс, по умолчанию 2000) — для окон, которые не сообщают Windows о смене активного окна.

Данные 0.1 переносятся автоматически (`data.json`, версия 3).

## Сборка

```
go test ./...
GOOS=windows GOARCH=amd64 go build -ldflags "-H windowsgui -s -w" -o NagaControl.exe .
```

Предпросмотр интерфейса без Windows: `NAGA_DUMP=/tmp/state.json go test -run TestDumpUIState .`, затем `python3 linuxtest/uimock.py /tmp/state.json 8765` и откройте `http://127.0.0.1:8765/?t=x`.
